# Nursery Management System 

##  Project Description
A web application for managing a nursery (plants, stock, customers, orders) with AI assistance.

##  Team Roles
- Workflow & Release Manager (Git & structure)
- Feature Lead (CRUD system)
- AI Lead (recommendation system)
- Refactoring Lead (code quality & design patterns)
- Quality Lead (SonarQube & testing)
- Business & Documentation Lead (documentation & presentation)

## 🛠️ Technologies
- Python (Flask)
- HTML / CSS
- Git & GitHub

## 📂 Project Structure
- backend logic in Flask
- frontend in templates/static
- documentation in docs/
- tests in tests/

## 🚀 How to run the project
```bash
pip install -r requirements.txt
python app.py
